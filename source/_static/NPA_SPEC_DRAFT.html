架构规格草稿

Nested Privilege Architecture — Architecture Specification Draft v0.3
状态：理论定论草稿（待实践打脸后修订）· 语言：中英术语混排以词表为准

P1–P6 I1–I28 lazy 内存 sec / csec

摘要。 NPA 将特权管理从固定 ISA 等级中解耦，改为内存可配置的域树。 域间控制转移仅有两个对称原语：descend（进入子域）与 ascend（回到父域调用点）。 特权配置存于 Domain Control Block (DCB)；执行现场存于 ISA 定义的 Context。 地址视图支持继承、继承+权限覆盖、叠加翻译；安全域区分普通（root 可见）与机密（root 不可见、须显式暴露）。

3. 原语与调用语义

3.1 闭集

原语语义
descend(dcb)进入子域（first → entry；resume → Context）。父挂起于调用点之后。
ascend(reason, x)回到父调用点。唯一向上原语。

reason 闭集

reason含义
SERVICE请求父服务（含 syscall/hypercall/SMC 等传统名）
RESULT正常结束，带返回值，可再 resume
EXCEPTION同步异常上报
EXIT域结束，不可 resume

服务号、参数经 ABI（如参数寄存器）传 x；Spec 不锁寄存器名。

3.2 调用时序

 parent                              child
   │                                   │
   │  create: write DCB                │
   │  (entry, edel, ipa, ptb, ...)     │
   │                                   │
   │  descend(dcb)  ─────────────────► │  first:  PC ← entry
   │  [HW saves return = next insn]    │  resume: PC ← Context
   │  (suspended)                      │
   │                                   │  ...
   │  ◄────────────── ascend(SERVICE,x)│  [HW saves child Context]
   │  PC = return point                │
   │  handle                           │
   │  descend(dcb)  ─────────────────► │  resume
   │                                   │
   │  ◄───────────────── ascend(EXIT)  │  lifecycle → TERM
   │  reap DCB (parent duty)           │

3.3 明确不设

不设理由
escalate / return_to_parent / return_to_child服务 = ascend + 再 descend
RETURN 原语resume 即再 descend
独立 exitascend(EXIT) 别名级
descend_n选子域是调用约定/软件
syscall/hypercall 指令名reason=SERVICE + 服务号
手动 MOV LR 返回不自然；返回点硬件自动
LR 兼 entrysaved_lr 双职
descend(dcb, entry) 热路径参数签名不净；entry 留 DCB

3.4 first / resume 透明性

软件永远只调用 descend(dcb)。first/resume 由硬件 lifecycle 判定。
  • entry 仅首次使用；返回点由硬件写入 Context（≈ ISA LR/RA）。
  • 返回参数 reason/x 按 ABI 可读。

4. 域生命周期

     create              descend            ascend(EXIT)           reap
   (写 DCB)                │                     │                 (父)
       │                   ▼                     ▼                   │
       ▼                ┌──────┐              ┌──────┐               ▼
    [FREE] ───────────► │ LIVE │ ───────────► │ TERM │ ──────────► [FREE]
       ▲                └──────┘              └──────┘               │
       │                   │  resume 保持 LIVE                        │
       └───────────────────┴───────────────────────────────────────────┘

 descend 路径:
   FREE → first   (PC ← entry, → LIVE)
   LIVE → resume  (PC ← Context)
   TERM → fault   (必须先 reap)
阶段谁动作
create父分配 DCB，配置字段；id 由系统唯一分配
run子+硬件descend/ascend；Context 自动保存恢复
exit子ascend(EXIT) → TERM；硬件清父 child 链接
reap父回收/重写 DCB → FREE；同址复用 = 新域

4.1 与 task_info 边界

DCBtask_info
性质架构/硬件状态内核软件结构
热路径只递对象 + descend调度簿记
lifecycle硬件自用，非 task 镜像OS 自定状态机
  • 软件可以借用 id/lifecycle 做映射；也可以自建表。
  • 禁止每次 syscall/schedule 批量改写 DCB 字段（I20）。

5. DCB 与 Context

5.1 分层

 ┌─────────────────────────────────────────────┐
 │ DCB = 特权配置与边界                           │
 │   父约束 / 域身份 / 翻译入口 / 父子链接        │
 ├─────────────────────────────────────────────┤
 │ Context = 执行现场（ISA 定义）                 │
 │   GPR, PC, SP, flags ...                     │
 ├─────────────────────────────────────────────┤
 │ task_info = OS 私有（pid, runqueue, mm ...）   │
 └─────────────────────────────────────────────┘

5.2 Spec Field（固定 10 words / 40 bytes）

off   name   owner    职责
──────────────────────────────────────────────────
0x00  sz     parent   大小（word），校验
0x04  id     system   域 ID（安全主键）
0x08  entry  parent   首次 PC
0x0C  edel   parent   异常委托 0|1
0x10  exc    child    本地异常入口
0x14  irq    system   中断实例 handle
0x18  ipa    parent   地址约束表
0x1C  ptb    child    页表基址（0=继承）
0x20  child  parent   当前子域 DCB
0x24  sec    system   安全组 handle
──────────────────────────────────────────────────
Impdef from 0x28 (e.g. isa)

字段权限：parent/system 子不可写；exc/ptb 子可写。

Spec 内禁止 saved_*、irq_saved_*、ABI 参数区。

5.3 Context（规范只约束动词）

  • descend / ascend / 进入 exc / 进入 IRQ 必须保存恢复完整执行上下文。
  • 存放位置与布局归 ISA；可为栈、slot、硬件 save area。

6. 事件模型

                    ┌────────────┐
   软件显式 ───────►│  ascend    │──► 父调用点
                    └────────────┘
   同步异常 ──┬─ edel=1 & exc≠0 ──► 本地 exc
              └─ 否则 ───────────► ascend(EXCEPTION)
   异步 IRQ ─────────────────────► irq 实例 vector

6.1 edel（exception delegation）

edelexc行为典型
0任意一律上交隔离 try、严格沙箱
10上交已授权未装 handler
1≠0本地；可再 ascendGuest 页错、语言运行时
  • 父在 create 时决定是否委托；不做按异常类型 mask。
  • Fault = 软件分类结果，非第三硬件入口。
  • 委托 ≠ 放权：越权访问永远失败（I14）。

7. 地址视图（lazy 内存）

7.1 三种形态

ptbipa翻译ipa 检查用途
00与父相同无try-catch、信任子域
0≠0与父相同VA（权限覆盖）MCU 沙箱、JIT 共页表
≠0*链：子VA→父视图→…→PA父视图地址用户 / 客户机
  叠加链:

    VA_child ──ptb_child──► IPA/PA_parent ──ptb_parent──► ... ──► PA

  INHERIT (ptb=0):

    VA ──(父翻译直接复用)──► ... ──► PA
    仅可被 ipa 表「收紧」权限，不得放宽或改写映射

7.2 lazy 语义

每次 load/store：翻译 → 权限(ipa) → 机密/密钥 → 才成功。无 cache 语义。

8. 安全与机密

8.1 角色

角色能不能
root trust装载 preset、bind、审计普通 sec被动读 csec 明文
安全子系统bind/attest、密钥、expose、伪装 Context—
父域配 DCB、调度、打断、reap读内容、取 csec 密钥
安全域自身读写自己的 sec/csec 内容越 ipa；伪造 bind

8.2 两种内容可见性

  普通 sec:   父 ✗   peer/lower ✗   root ✓   owner ✓
  机密 csec:  父 ✗   peer/lower ✗   root ✗   owner ✓
              （显式 share 窗后，被授权方才可见对应页）

8.3 控制权 vs 可见性

父域可用高优先级中断等打断安全域；csec 只是「看不到内容」，不是不可管理。

8.4 伪装 Context（csec）

   csec 运行
        │ preempt / IRQ
        ▼
   安全子系统
     ├─ 真 Context ──保管──► 安全侧
     └─ 伪 Context ─────────► 父域 (token / 空壳)
                                    │
   父: 入队 / 再 descend(dcb)        │
        │                            │
        ▼                            │
   安全子系统: 校验 token ──► 还原真 Context ──► 继续 csec
  • 伪装不得泄露真 PC/寄存器（除非 root+授权审计策略）。
  • token 与 lifecycle 绑定；TERM/reap 后失效。
  • 普通 sec（root 可读）可给真 Context；csec 默认伪装。

8.5 密钥

  • 区域密钥由安全子系统生成/注入引擎；不进 DCB Spec。
  • 父无 K：即使知道 PA 也不能得明文。
  • csec 仅 ascend(x) / 共享窗等显式暴露后对外可见。
  • 接口要求：preset / bind / attest / key_set_region / expose / check_access。
  • 算法与 root trust 存放：实现选择。

8.6 secure lib

不单列类型：= 小或复用地址空间的 sec/csec，验码后短跑 EXIT（I26）。

10. 优化约束（cache）

  • cache/TLB 只加速，不改变 lazy 语义下的成功/失败/明文。
  • TLB 项须含域标签；ptb/lifecycle/reap 后旧项不可见。
  • 机密区不得因 cache 让无钥访客得到明文。
  • 绝对性能周期数不属本规格（gem5/硬件）。

11. 不变量索引

ID一句话
I1–I2向上仅 ascend；父恢复点 = descend 之后
I3/I18entry 不兼返回点；descend(dcb) 唯一形态
I4Spec 无 saved_*/ABI 字段
I5–I6异常不静默丢；INHERIT 无叠加
I7子不可写 parent/system 字段
I8–I10语义不偷渡新原语；一名一义；冲突须修订
I11–I12ptb=0 只收紧权限；纯 INHERIT 不宽于父
I13–I14edel=0 必上交；越权必失败
I15命名词表（id / parent-child / δ）
I16–I17bind 校验绝对 id；TERM 拒 resume
I19–I20无 task_info 进 Spec；热路径不批量改 DCB
I21–I24lazy；bind 链；密钥归属；密钥不进 Spec
I25–I26csec 含 root 不可读；secure lib = 小 sec/csec
I27–I28可打断不可窥探；csec 伪装 Context
